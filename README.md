# 🛡️ Bharat CyberShield

An AI-powered Cyber Security Platform that detects phishing attacks, malicious QR codes, scam SMS messages, and fraudulent emails using machine learning, threat intelligence APIs, and explainable AI.

---

## 📷 QR Code Security Scanner
- Upload QR code images
- Live camera QR scanning
- QR text decoding
- URL & UPI QR detection
- Phishing URL detection
- Malware URL detection
- Explainable AI risk analysis
- Risk score generation

- Scan history

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/joel220013-sys/bharat-cybershield.git
```

## Backend

```bash
cd backend

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```
